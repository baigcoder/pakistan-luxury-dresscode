# 16 — Project Memory

## Creative memory

The site is an original Pakistani luxury fashion house inspired by the high-level design discipline of the Dresscode Dribbble reference.

The most important qualities are:

- image-first composition
- sparse UI
- warm neutral palette
- editorial typography
- premium fashion photography
- subtle motion
- strong whitespace
- Pakistani textile/craft provenance

## Implementation memory

When an implementation decision is ambiguous, prioritize:

1. brand clarity
2. product discoverability
3. performance
4. accessibility
5. motion polish

before adding decorative effects.
