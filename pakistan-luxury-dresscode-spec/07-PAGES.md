# 07 — Page-by-Page Design Specification

## Home

### Section 01 — Hero

- full viewport
- fashion campaign image/video
- minimal navigation
- eyebrow
- oversized headline
- quiet CTA
- optional collection metadata

### Section 02 — Collection Introduction

- large editorial statement
- one dominant image
- secondary image offset on grid

### Section 03 — Horizontal Collection Rail

- 4–8 collections
- vertical scroll drives horizontal movement on desktop
- drag/swipe on touch devices

### Section 04 — Craft Macro

- extreme fabric close-up
- scroll-controlled scale transition
- small provenance metadata

### Section 05 — Full-Bleed Campaign

- cinematic photography
- small text anchor
- subtle reveal

### Section 06 — Selected Pieces

- editorial product grid
- 2/3/4 columns depending on width

### Section 07 — Journal

- 3–4 feature cards
- asymmetrical placement

### Section 08 — Newsletter / Footer

- one-line statement
- email field
- footer navigation

## Collection page

Hero → intro → filter row → product grid → editorial interlude → remaining grid → footer.

## Product page

Left: oversized media gallery.
Right: product metadata, price, size, add-to-bag, details.

Below: campaign image → detail macro → craft story → related products.

## Craft page

- regional index
- technique index
- macro imagery
- artisan story
- material story
- related products/collections

## Journal index

Large lead story → grid of smaller stories → category filter.

## Journal article

Large title → hero image → metadata → longform body → inline images → related products/collection.

## About

Manifesto → house timeline → design philosophy → craft → studio images → contact.

## Search

Fullscreen utility panel with live suggestions, recent searches, collections, products and articles.

## Cart

Prefer side drawer on desktop and full-screen sheet on mobile.
