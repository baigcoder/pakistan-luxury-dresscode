# 09 — Interaction Design

## Cursor states

Desktop only:

```text
DEFAULT
VIEW
SHOP
PLAY
DRAG
OPEN
```

Cursor labels should be small and unobtrusive.

## Header behavior

At top:
- transparent or tonal over hero

After scroll:
- subtle surface/background
- compact height
- preserve easy access to utilities

## Mega menu

- open from primary nav
- large category labels
- subcategories
- featured campaign image
- close with Escape
- trap focus while open

## Search

- open as overlay
- autofocus input
- keyboard navigation
- category chips
- recent searches
- instant result grouping

## Quick view

Use only where it speeds shopping. Never replace the full product page.

## Wishlist

Optimistic UI with accessible pressed state.

## Add to Bag

- button feedback
- cart count update
- optional side drawer
- preserve scroll position
