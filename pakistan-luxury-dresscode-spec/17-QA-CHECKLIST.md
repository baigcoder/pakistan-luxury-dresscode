# 17 — QA Checklist

## Visual

- hero alignment correct
- display type never clips
- image crops preserve models/garments
- grid aligns across sections
- palette remains restrained

## Motion

- no layout jumps
- no scroll jank
- no excessive parallax
- hover states subtle
- reduced motion works

## Commerce

- product tile links work
- filters are usable
- size selector works
- add to bag works
- cart persists as intended
- wishlist toggles correctly

## Accessibility

- keyboard path complete
- focus visible
- overlays trap focus
- Escape closes overlays
- images have correct alt treatment
- contrast acceptable

## Responsive

- 375px
- 430px
- 768px
- 1024px
- 1280px
- 1440px+

## Performance

- hero optimized
- below-fold media lazy-loaded
- no giant JS bundle without reason
- no console errors
- no hydration warnings
